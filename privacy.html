ReadMate / 读伴 — 隐私政策 (Privacy Policy)

生效日期：2026年9月6日  |  适用版本：ReadMate 1.0.0+
核心承诺 (Core Commitment)：
读伴（ReadMate）严格秉持“本地优先、零数据收集”原则。作为一款纯净的网页朗读、生词辅助与专注阅读工具，我们绝不收集、绝不存储、绝不上报、绝不转售用户的任何个人身份信息（PII）、浏览历史或网页阅读记录。

1. 数据处理与权限使用说明 (Data Usage & Permissions)

  • 本地配置持久化 (storage)：您的个性化设置（如朗读语速、音色偏好、双语对照开关、以及您自行填写的 AI API Key）仅安全存储在您浏览器本地的 chrome.storage.sync 中，仅用于扩展功能的正常运行与跨设备同步，绝不会上传至任何第三方服务器或数据分析平台。
  • 页面阅读与高亮 (activeTab & scripting)：仅当您主动点击朗读、双击单词查词或开启沉浸净读模式时，扩展才对当前活跃标签页的正文进行段落与分句解析，以便实现声画同步跟随高亮。所有文本解析均在您的浏览器本地内存中执行，页面关闭即销毁。
  • 快捷右键菜单 (contextMenus)：仅用于在鼠标选中文本时提供“朗读选中文字”的系统级便捷入口。
  • 大模型翻译与核心摘要 (AI Services)：当您主动发起 AI 摘要或深度翻译时，相关句子或段落仅在您点击时实时发送至您在设置中指定的标准化 API 接口（如 OpenAI 官方或 DeepSeek 官方），读伴本身不设立任何中间数据中转站，不留存任何明文数据。

2. 权限最小必要化 (Minimum Permission Principles)

读伴严格遵守 Google Chrome Web Store 的最小必要权限要求，已全面剔除诸如 downloads 等冗余权限，所有导出的 PDF 与音频文件均通过前端本地 Blob 协议直接保存至您的设备。

3. 无广告与零商业追踪承诺 (No Ads & Tracking Free)

读伴承诺：

  • 绝不植入任何第三方广告联盟 SDK；
  • 绝不加载 Google Analytics 等行为追踪脚本；
  • 绝不建立用户画像，绝不将任何数据转售给数据经纪人或营销机构。

4. 政策更新与联系方式 (Contact Us)

本隐私政策若有任何调整，将在此页面同步发布最新版本。
